# alaye-build

MABOOST SOCIAL — simple static marketing site.

Live preview (after enabling Pages):
https://mavibezz.github.io/alaye-build

What I added
- index.html (site homepage)
- css/style.css and js/site.js placeholders so the homepage loads without 404s
- order.html, status.html, support.html placeholder pages

To publish with GitHub Pages (manual):
1. Go to: Settings → Pages
2. Under "Source", select Branch: main and Folder: / (root)
3. Save — the site will be available at the URL above within a minute or two.

If you want automatic deploys or a build step, I can add a GitHub Actions workflow that deploys to gh-pages or config for Netlify/Vercel.
